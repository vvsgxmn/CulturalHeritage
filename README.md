# 基于SpringBoot+Vue的文化遗产管理系统

![Spring Boot](https://img.shields.io/badge/-Spring%20Boot-6DB33F?style=flat-square&logo=spring-boot&logoColor=white) ![Vue3](https://img.shields.io/badge/-Vue3-grey?style=flat-square) ![MySQL](https://img.shields.io/badge/-MySQL-4479A1?style=flat-square&logo=mysql&logoColor=white) ![MyBatis](https://img.shields.io/badge/-MyBatis-000000?style=flat-square&logo=mybatis&logoColor=white) 

## 项目介绍

CulturalHeritage 是一款面向文化爱好者与文博管理人员的数字化遗产保护平台，支持遗产档案数字化、传承人谱系、修缮前后对比、研学预约核销、资讯发布与 AI 文博向导，公众端与管理中台双端协同，适合毕设、课设与学习参考。

## 主要功能模块

- **公众展陈模块**：展陈大屏、遗产档案筛选与详情、传承大师与修缮纪实浏览
- **研学预约模块**：研学活动排期、在线预约、核销码生成与个人预约管理
- **文博资讯模块**：新闻公告科普发布、Markdown 阅读与阅读量统计
- **管理中台模块**：数据大屏、档案分类、传承人、修缮工程、预约审核核销与用户管理
- **权限认证模块**：普通用户/管理员双角色登录，JWT 鉴权与路由隔离
- **AI 文博向导模块**：通义千问兼容接口，支持文博相关问答与对话审计

## 技术架构

- **后端**：Spring Boot 2.7.18 + MyBatis-Plus + JWT + Lombok
- **前端**：Vue 3.5 + TypeScript + Vue Router + Pinia + Element Plus + Vite 5 + ECharts
- **数据库**：MySQL 8.0
